================================================================================
                        REINOS ANCESTRALES - 3DAODRAG
                     Guia de Desarrollo y Funciones Pendientes
================================================================================

PROYECTO: Reinos Ancestrales (3daodrag)
TIPO: RPG 3D Browser Game (PWA)
STACK: Three.js + TypeScript + Vite + Express + JWT
IDIOMA: Todo el contenido en ESPAÑOL
ESTADO: Fase 1 y 2 completadas - Seguridad e Infraestructura

================================================================================
                        ARQUITECTURA DEL SISTEMA
================================================================================

Frontend (src/):
  - main.ts          → Login, creacion de NFT, flujo de autenticacion
  - game/game.ts     → Core Game: loop, combate, UI, interacciones
  - game/world.ts    → Generacion del mundo: zonas, enemigos, recursos, NPCs
  - game/nft.ts      → Sistema de personajes NFT: generacion procedural, traits
  - game/profile.ts  → Perfil del jugador, inventario, quests, crafting
  - game/input.ts    → Controlador de entrada: teclado + joystick tactil
  - game/api.ts      → Cliente HTTP para auth y perfil API
  - game/zones.ts    → Configuracion de zonas y deteccion de proximidad
  - game/rewards.ts  → Sistema de recompensas QR
  - game/qr-scanner.ts → Scanner QR con Barcode Detection API
  - game/quality.ts  → Deteccion automatica de calidad grafica

Backend (server/):
  - index.js         → Express server con JWT auth, CRUD de perfiles
  - data/db.json     → Base de datos JSON flat-file (2 usuarios registrados)

================================================================================
                        SISTEMAS ACTUALES IMPLEMENTADOS
================================================================================

1. SISTEMA DE PERSONAJES NFT
   - Generacion deterministica desde hash de numero de telefono
   - PRNG seeded (mulberry32) para traits unicos
   - Elementos: fuego, agua, tierra, aire, sombra, luz
   - Rareza: comun, raro, epico, legendario (con pesos de probabilidad)
   - Tipo de cuerpo: humanoide, bestia, espectral, golem
   - 5 stats: ATK, DEF, SPD, HP, Habilidad
   - Modelo 3D procedural con Three.js primitives

2. SISTEMA DE COMBATE
   - Accion: ataque automatico al enemigo mas cercano (400ms cooldown)
   - IA enemiga: persecucion, rango de ataque, calculo de dano
   - 4 tipos de enemigos: lobos, espirites, esqueletos, golems
   - Loot drops con tablas de probabilidad
   - Sistema de vida/energia, respawn al morir

3. ZONAS (3 actuales)
   - Aldea: zona inicial, NPCs basicos
   - Bosque Ancestral: recursos, enemigos medios
   - Ruinas Antiguas: enemigos dificiles, crafting avanzado
   - Desbloqueo progresivo via quests

4. SISTEMA DE QUESTS (7 misiones)
   - Recoleccion de recursos + eliminacion de criaturas
   - Recompensas XP y items
   - Desbloqueo de zonas al completar

5. SISTEMA DE CRAFTING (5 recetas)
   - Racion (1 trigo), Espada (2 mineral), Pocion (2 esencia)
   - Escudo (2 madera), Unguento (2 hierba)
   - Consumibles con valores basados en stats

6. NPCs
   - Dialogos por zona
   - Sistema de trade/intercambio

7. SISTEMA QR
   - Escaneo de camara para codigos de factura
   - Codigos demo: TABERNA, PANADERIA, FOGATA, MERCADO
   - Puente comercio fisico → juego

8. OPTIMIZACION
   - 3 niveles de calidad: baja, media, alta
   - Auto-deteccion segun dispositivo
   - Frame rate caps: 30/45/60 FPS

9. PWA
   - Service Worker para offline
   - Instalable como app movil

COMANDOS DISPONIBLES:
  npm run dev      → Iniciar frontend con Vite
  npm run server   → Iniciar backend Express
  npm run start    → Iniciar ambos (concurrently)
  npm run build    → Build de produccion (tsc + vite build)
  npm run preview  → Preview del build

VARIABLES DE ENTorno REQUERIDAS (server):
  JWT_SECRET       → Secreto para JWT (requerido en produccion)
  PORT             → Puerto del server (default: 3000)
